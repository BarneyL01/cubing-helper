# 2026-09-26 — v1 site build

- User confirmed the decoded mnemonic cipher (including the previously
  flagged Z-perm) is correct. `docs/mnemonics.md` updated to reflect that.
- Built the v1 static site:
  - `index.html` — landing page linking to all puzzles/methods
  - `css/style.css` — shared styling (light/dark via `prefers-color-scheme`)
  - `js/algs.js` — `invertAlg`/`invertMove` helpers (used to derive each
    case's "before" state from its solving algorithm, so the setup shown in
    the 3D preview can never drift out of sync with the algorithm text)
  - `js/render-cases.js` — renders an array of case objects into cards, each
    with an embedded `<twisty-player>` (cubing.js, loaded from
    `cdn.cubing.net`), the WCA algorithm, and the mnemonic breakdown
  - `data/oll.js`, `data/pll.js` — the decoded algorithm data for all 8 OLL
    cases and 6 PLL cases (Y-perm, T-perm, Ua, Ub, H, Z) from the user's notes
  - `3x3/cfop/index.html`, `oll.html`, `pll.html`
  - Placeholder "coming soon" pages: `3x3/roux/`, `3x3/beginners/`, `2x2/`,
    `megaminx/`
- Verified: every case's mnemonic-chunk moves concatenate to its declared
  algorithm (checked programmatically, one intentional exception — the
  T-perm's Prefer+Jolly boundary merges two adjacent `R` turns into `R2`,
  which is expected and already reflected in the displayed algorithm); all
  pages/assets serve correctly from a local static server.
- Static 2D diagrams (the classic "3x3 grid + side stickers" OLL/PLL
  pictures) were **not** added yet — hand-drawing them risks getting the
  sticker pattern wrong, which defeats the point of a reference tool. The
  interactive 3D twisty player is mechanically correct instead (it's driven
  directly by the algorithm data via `invertAlg`, not hand-drawn), so it
  covers the "graphics" requirement accurately for v1. Static diagrams are
  a good follow-up once we have a reliable source for them.
- The `Uv` OLL case has no primary algorithm in the original notes — only
  the alt algorithm is shown, flagged in the UI.
