3-Style solves

Small blind solves with only the 3-style corner pairs you choose: the base groups and setup lengths you are learning from the By base page. Edges stay solved.

Made here (2026-11-05). Each scramble picks pairs from your choice that use different corners and undoes them, using the commutators of the 3-Style page or Dylan's sheet, so the scramble does not spell out the answer (for some pairs, such as a base with no setup, every table has the same commutator, so then it does). Every scramble is checked on the simulated cube before it is shown: the corner memo from C is exactly the chosen pairs, and the solution solves it.
