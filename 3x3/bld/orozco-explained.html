      Part by part

      Starting from a solved cube, so you can follow where each corner goes.

      Why only three corners move

      • X changes only one spot in the top layer: the helper spot. The rest of the top layer is untouched.
      • Y puts a different corner into that spot (the buffer piece).
      • Undo X reverses X for that spot, but the corner it sends down is now the buffer piece, not the one that came up. Everything else X moved goes back.
      • Undo Y turns the top layer back.
      • With a setup, the same happens with the target's corner moved first to where the base expects it, and moved back at the end.

      Halfway through (after Y) the cube looks badly broken; that is normal.

      Run it

      Step through the moves one at a time, or press Play: each layer turns on screen. Drag the cube to look at any side.

      The other letters

      • O, H and L are the three bases with no setup: only the D turn inside X changes (D, D', D2), which picks a different bottom corner.
      • K shows a setup: one D turn first brings K's corner to where the base expects it, and it is undone at the end.
      • Every other Orozco letter works the same way: see the Orozco page, By base.
      • Done backwards (the 2nd letter of a pair), the same three corners move the other way round.
