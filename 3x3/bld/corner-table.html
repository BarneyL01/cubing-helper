1. Easiest cycles to learn

Each direct pair is an 8-move commutator: a single-turn interchange and a 3-move insertion. Learn them one layer at a time.

  1. D layer first. The buffer is always one of the two corners the D turn swaps. You find only the other two.
  2. U layer next. The U turn swaps two target corners, and the insertion brings the buffer up.
  3. Side layers last (R, L, F, B turns), which have the most shapes.
  4. Then pairs with one setup move (section 3), once the direct ones feel familiar.

Every pair is in the lookup (section 4). This list only suggests an order.

2. Choosing a setup move

Some pairs have no direct commutator. Then use a setup move that brings a target sticker to where the Commutators tab's five steps work, and undo it afterwards.

  1. Try to build the commutator directly (the Commutators tab, "Building one yourself").
  2. If that fails, do one move that puts a target sticker where step 1 works. Prefer a move that leaves the buffer alone. Do the commutator, then undo the move.
  3. If no single move works, try two moves (or three for the hardest pairs).

No simple rule says which pairs need a setup; the table is the full list.

    3. How to use a setup move

    1. Look up the pair. Its row gives the setup, if it has one.
    2. Do the setup. It moves the two target stickers to where a direct commutator works.
    3. Do the commutator. It solves the pair the setup leaves you with.
    4. Undo the setup: reverse the order and invert each turn. R' F' is undone by F R.
